# おがわ歯科 シフト管理アプリ

共有PCのブラウザで動く、シフト表の作成アプリです。インストールは不要で、`index.html` をダブルクリックすると開きます。

- スタッフが希望休・有給を入力します（名前を選ぶだけ）。
- 管理者が下書きを自動作成します。常勤の休み（祝日以外に月8日）はアプリが割り振ります。
- 表を見ながら手で直し、確定・印刷・Excel 用の書き出しをします。
- 入職・退職・産休・育休の日付も管理できます。

仕様の詳細は [docs/requirements.md](docs/requirements.md) にあります。

## 最初の準備（1回だけ）

1. このページの上にある緑の「Code」ボタン →「Download ZIP」を押します。
2. ダウンロードした `ogawa-shift-app-main.zip` を右クリック →「すべて展開」で解凍します。
3. できた `ogawa-shift-app-main` フォルダを、共有PCの決まった場所（例: `ドキュメント`）に置きます。**置いた後は場所も名前も変えません。**
4. フォルダの中の `index.html` を右クリック →「プログラムから開く」→ Chrome か Edge を選びます。ブラウザのブックマークに登録しておくと次から楽です。
5. 「管理者」タブで管理者パスワードを決めます。
6. 「管理者」→「バックアップ」→「バックアップから復元」で、初期データのファイル（`おがわ歯科_初期データ.json`。管理者が別に保管）を読み込みます。
7. 「管理者」→「スタッフ」で、一人ずつ職種・雇用・基本パターンを確認して直します。初期データは6〜8月のシフト表から推定したものです。
8. 「管理者」→「設定」で、最少人数と診療時間を確認します。

## 毎月の流れ（例: 12月分）

| 時期 | 誰が | すること |
|---|---|---|
| 10月25日まで（前々月の25日） | 各スタッフ・代表者 | 「希望休・有給の入力」で名前を選び、日付を押して入力する |
| 10月26日〜31日 | 管理者 | 「シフト作成」で休診日・急患対応日を設定 →「下書きを自動作成」→ 表を見て修正 |
| 11月1日まで（前月の1日） | 管理者 | 「確定する」→ 印刷して掲示 → バックアップを保存 |

締切を過ぎると、スタッフは入力できなくなります。管理者がログインしている間は、締切後でも代わりに入力できます。

## 自動作成のルール

**必ず守ること**
- 希望休と有給は、そのまま反映します。
- 最少人数（初期値: Dr1・DH2・DA1・受付1・CS1）を下回るような休みは入れません。
  - CS は「1日に1人以上」、ほかの職種は「午前・午後それぞれ」で数えます（「設定」で変更できます）。
  - DA と受付の兼任者は、足りない方に数えます。

**常勤の休みの数え方**
- 祝日を除いて、月8日の休みにします。
- 半日勤務の日は0.5日の休みと数えます。
- 休診日（年末年始・お盆など祝日以外）は休みに数えます。
- 有給は8日に含めません。研修・セミナーは出勤扱いです。
- 途中入職・退職・育休の月は日割りにします（例: 30日中15日在籍なら4日）。

**なるべく守ること**
- 連続勤務は5日まで（「設定」で変更できます）。
- 土日の休みが特定の人に偏らないようにします。
- 休みが月初や月末に固まらないように散らします。
- 出勤人数の多い日から休みを入れ、日ごとの人数をならします。

パート・非常勤の人は基本パターンどおりに出勤し、自動の休みは入りません。守れなかった点は、画面の「確認が必要な点」に一覧で出ます。

## 表の見方

| 表示 | 意味 |
|---|---|
| 〇 | 終日出勤 |
| AM / PM | 午前のみ / 午後のみ |
| 17時まで・16時〜・10〜13時 | 時間指定 |
| × | 休み（青い太字の × はアプリが自動で入れた休み） |
| 有給 | 有給休暇 |
| ー | 勤務なし・休診日 |
| 育休・入職前・退職 | 在籍していない期間 |
| マスの左のオレンジ線 | 本人の申請どおり |
| 太い枠 | 管理者が手で直したマス（作り直しても残ります） |
| 人数欄の赤 | 最少人数より少ない職種 |

マスを押すと中身を直せます。「表に表示する文字」に「セミナー」などを入れると、記号の代わりにその文字が出ます。

## データの保存とバックアップ（重要）

データはこのPCのブラウザの中にだけ保存されます。次の場合は見えなくなったり、消えたりします。

- PCが壊れたとき、別のPCや別のブラウザで開いたとき
- ブラウザの「閲覧履歴データの削除」で「Cookie と他のサイトデータ」を消したとき
- アプリのフォルダの場所や名前を変えたとき

そのため、**シフトを確定したときと2週間に1回**、「管理者」→「バックアップ」→「バックアップをファイルに保存」を押します。保存したファイルは USB メモリなど PC 以外の場所にもコピーします。14日以上保存していないと、管理者画面に注意が出ます。

データが消えたときは、「バックアップから復元」で保存したファイルを選びます。

## 困ったとき

**パスワードを忘れた**
ブラウザのアドレス欄で、`index.html` の後ろに `#reset-admin` を付けて開きます（例: `file:///C:/Users/.../ogawa-shift-app-main/index.html#reset-admin`）。確認が出たら「OK」を押し、新しいパスワードを決めます。このパスワードは誤操作を防ぐためのもので、強い防犯機能ではありません。

**印刷の色が出ない**
印刷画面の「詳細設定」で「背景のグラフィック」をオンにします。用紙は A4 横です。

**祝日が変わった**
祝日は2099年まで自動で計算します。法律の改正などで祝日が変わった場合は、「シフト作成」→「診療日の設定」でその日を直します。

## ファイル構成（開発者向け）

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の土台 |
| `app.css` | 見た目（印刷用の設定を含む） |
| `core.js` | 計算（祝日・締切・休みの自動割り振り・人数チェック）。画面に依存しない |
| `ui.js` | 画面の表示と操作、データの保存 |
| `test/core.test.js` | `core.js` のテスト |

テストの実行（Node.js が必要）:

```bash
node --test
```

## アプリの更新

新しい版が出たら、同じ手順で ZIP をダウンロードし、共有PCのアプリのフォルダの中身を上書きします。入力済みのデータはブラウザ側にあるので消えません。念のため、上書きの前にバックアップを保存してください。
